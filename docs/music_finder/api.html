Music Finder API

Use Music Finder’s song suggestions in your own app.

Music Finder runs entirely in the browser, so its “API” is a script your web app loads. Your app then asks the same free music services directly. There are no keys, no accounts and no limits beyond those services’ own.

1. Add the script

<script src="https://testserhere.github.io/music_finder/api.js"></script>

2. Ask for songs

const result = await MusicFinder.recommend({
  songs: [
    { title: 'Yellow', artist: 'Coldplay' },
    { title: 'Creep', artist: 'Radiohead' },
  ],
  count: 20,
});

result.source;   // 'deezer', the source that answered
result.songs;    // [{ title, artist, art, preview, youtube, link, reason, source }, ...]

Or ask by genre: MusicFinder.recommend({ genre: 'jazz' }).

Options for recommend()

OptionWhat it does
songs1 to 3 songs you like, each { title, artist }.
genreInstead of songs, any genre, like 'rock' or 'shoegaze'.
source'auto' (default) tries Deezer, ListenBrainz, YouTube then Apple Music until one works. Or name one.
countHow many songs, 1 to 50. Default 20.
excludeSongs to leave out, like ones already in your library. Each { title, artist }.
avoidArtistsArtist names to leave out. This is how your app can do “less like this”.

What each song has

FieldMeaning
title, artistThe song.
artCover art address, or empty.
previewA 30-second audio clip you can play with new Audio(song.preview), or empty.
youtubeA YouTube video id when the song came from YouTube, or empty.
linkThe song’s page on the source.
reasonWhy it was picked, like “Similar to Coldplay”.

Other helpers

await MusicFinder.search('yellow coldplay');           // songs matching typed words
await MusicFinder.preview({ title, artist });        // a preview address for any song, or ''
await MusicFinder.sources();                         // [{ id, name, about }]
await MusicFinder.genres();                          // ['Pop', 'Rock', ...]
MusicFinder.link({ songs: [{ title, artist }] });    // a link that opens Music Finder with that search

Not a web app?

Apps that aren’t web pages can open Music Finder with a link instead, for example:

https://testserhere.github.io/music_finder/?song=Coldplay%20-%20Yellow&song=Radiohead%20-%20Creep&source=deezer
https://testserhere.github.io/music_finder/?genre=jazz

A server or phone app that wants plain JSON would need a small server of its own to run this code, because GitHub Pages can only serve files.
